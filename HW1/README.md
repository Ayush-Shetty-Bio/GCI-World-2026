# Homework 1

## Topic

NumPy array manipulation and computational problem solving.

## Objective

Implement a function that takes a 1D NumPy integer array and returns
the elements that are both multiples of 5 and odd.

## Approach

The solution uses NumPy boolean masking to apply two conditions:

- The element must be divisible by 5.
- The element must be odd.

Both conditions are combined using the & operator.

## Bioinformatics Connection

Boolean filtering is a fundamental operation in computational biology
and bioinformatics. Similar approaches can be used to filter numerical
biological datasets, sequence-derived features, molecular descriptors,
and experimental measurements according to defined criteria.
